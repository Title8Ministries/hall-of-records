# The Hall of Records — vertical slice

A working slice of the cinematic rebuild of josephfainmcdaniel.com. **Not the live
site**, and not a finished film — this is the opening beat, built to prove the
world, the choreography and the performance contract before the full build.

**What is in this slice:** the Seal → Waters opening. Joseph's own signature and
thumbprint, his registered marks, drive the scene — the print is a displacement
and normal map, so the ridges are physically sunk into the wax and found by a
single raking key light. One camera move (descend). WebGL via Three.js, ACES tone
mapping, bloom, grain, vignette.

`?t=<seconds>` seeks to any beat.
